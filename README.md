# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I.

## Integrantes

- Nome do aluno 1
- Nome do aluno 2 (se houver)

## Como jogar

Digite uma letra e clique em **Tentar** (ou pressione Enter). O objetivo é descobrir a palavra antes de acabar as tentativas. Use a dica exibida na tela para ajudar.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Palavra aleatória (12 palavras)
- Dica para cada palavra
- Controle de tentativas (6)
- Letras utilizadas e bloqueio de letras repetidas
- Mensagens de vitória e derrota
- Envio da letra com Enter
- Placar de partidas, vitórias e derrotas
- Reinício da partida
